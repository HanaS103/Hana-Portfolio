Wine Quality Analysis & Prediction

Project Overview

This project focused on analyzing wine quality data and predicting wine ratings using machine learning and data analysis techniques.

The project explored relationships between alcohol levels, acidity, sugar content, sulfur dioxide, pH, density, and overall wine quality.

My Role

My role in this project was Visualization. I helped create and present charts, visual findings, and presentation visuals for the project.

Main Questions Explored

  • What factors influence wine quality?
  • Does alcohol impact wine quality?
  • What differences exist between red and white wine?
  • Which variables are most important?

Key Findings

  • Alcohol showed a strong positive relationship with wine quality
  • Volatile acidity negatively affected wine quality ratings
  • Red and white wines showed different chemical compositions
  • Machine learning models successfully predicted wine quality trends
