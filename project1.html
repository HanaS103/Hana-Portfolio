Project 1: Personal Portfolio Website

This project is a personal portfolio website designed and developed using HTML and CSS. The goal of this project was to create a professional website that introduces me, showcases my projects, and demonstrates my web development skills.

Project Goals

  • Create a multi-page website
  • Practice HTML and CSS skills
  • Build a clean and organized layout
  • Publish the website using GitHub Pages

Technologies Used

  • HTML5
  • CSS3
  • GitHub
  • GitHub Pages

Challenges

One challenge I faced was organizing navigation between multiple pages and keeping the design consistent throughout the website.

What I Learned

Through this project, I learned how to structure a portfolio website, style pages with CSS, link pages together, and deploy a live website online using GitHub Pages.
